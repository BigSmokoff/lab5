# Интеграция 2D решателя в препроцессор (SolidFoamNC)

**Цель**: Внедрить параметрический эскизник в наш GUI препроцессор на C++/Qt6, чтобы геометрия для CFD сетки (OpenFOAM) могла управляться размерами.

**Задачи**:
1. Адаптировать структуру данных [[Граф геометрических ограничений]].
2. Настроить UI (Qt Graphics View Framework) для отрисовки примитивов и наложения связей.
3. Интегрировать численный решатель ([[Метод Ньютона-Рафсона в решателе]]) для перестроения сетки при изменении параметров.

Архитектура должна быть отвязана от MFC, полная ставка на Qt6.
