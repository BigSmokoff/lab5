# Прототип 2D CAD на Qt6

Изолированный пет-проект для обкатки математики [[Геометрический решатель (2D Solver)]], без тяжеловесных API.

**Стек**: CMake, C++20, Qt6.
**Функционал**:
- Отрисовка отрезков и окружностей.
- Подсчет [[Степени свободы (DOF)]].
- Применение ограничения "Совпадение точек" (Coincidence).
- Решение системы через простейший [[Метод Ньютона-Рафсона в решателе]].

Отличный полигон для практики архитектурных паттернов из [[Книга А.В. Столярова Введение в профессию]].
