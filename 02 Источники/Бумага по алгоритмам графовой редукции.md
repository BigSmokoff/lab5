# Бумага по алгоритмам графовой редукции

**Основная тема**: применение обобщенной теоремы Ламана (см. [[Условие жесткости Ламана (Laman rigidity)]]) для декомпозиции систем уравнений.

В статье детально разбирается [[Алгоритм DR-Planner]] и приводится псевдокод для определения плотных (dense) подграфов. Это основной референс для реализации символьного этапа в моем [[Прототип 2D CAD на Qt6]].
