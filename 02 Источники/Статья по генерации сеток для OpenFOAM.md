# Статья по генерации сеток для OpenFOAM

**Краткая суть:**
Анализ подходов к созданию расчетных сеток для CFD. Сравнивается стандартная утилита `snappyHexMesh` с кастомными алгоритмами тесселяции. 

Для интеграции в [[SolidFoamNC Архитектура плагина]], статья дает понимание того, как правильно экспортировать границы 2D-эскиза (преобразованные в 3D поверхности) в формат STL или OBJ, чтобы сеточный генератор смог корректно разрешить пограничные слои (boundary layers) и избежать вырожденных ячеек. Это критично для сходимости решателя OpenFOAM.
