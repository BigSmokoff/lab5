# Официальная документация Qt6 Graphics View Framework

Основной справочный материал для разработки кастомного 2D CAD интерфейса.

Фреймворк базируется на паттерне MVC ([[Паттерн MVC в разработке САПР]]):
- **QGraphicsScene** (Модель): хранит логику, пространственный индекс (BSP-дерево) для быстрого поиска объектов по координатам, управляет миллионами 2D-примитивов.
- **QGraphicsView** (Представление): виджет-контейнер, отвечающий за рендеринг, масштабирование (зумирование), панорамирование (паннинг).
- **QGraphicsItem** (Элементы): базовый класс для геометрии (линии, дуги, узлы ограничений). Для кастомных CAD-объектов необходимо переопределять методы `boundingRect()`, `shape()` (для точного определения коллизий) и `paint()`.

Тщательное изучение `QVariant` и `ItemIsSelectable` | `ItemIsMovable` сильно ускоряет разработку интерактива.
