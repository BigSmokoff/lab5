# Документация API для разработки плагинов (NRX)

API (NRX / .NET) для интеграции в САПР платформу.
Опыт разработки кастомных примитивов (как `AcDbTangentCircles`) показал, что для полноценной интеграции нужно правильно реализовать COM-обертки и обработку событий.

При подключении внешнего [[Геометрический решатель (2D Solver)]], необходимо реагировать на изменения `Osnap` (объектных привязок) и перестраивать геометрию в callback-функциях API.
