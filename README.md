# База Знаний: 2D CAD Solver & Инженерная разработка

Данное хранилище (Vault) для Obsidian представляет собой структурированную базу знаний, посвященную разработке параметрического 2D-решателя (геометрического ядра), интеграции математических алгоритмов на C++ и созданию графических интерфейсов на Qt6.

База спроектирована по принципам Zettelkasten и Map of Content (MOC), что позволяет легко связывать теорию, архитектурные решения и ежедневные задачи.

## Структура директорий

Хранилище разделено на 7 основных категорий для строгой изоляции типов контента:

- **01 Заметки**: Атомарные концептуальные записи. Здесь хранится ядро знаний: математика (матрицы Якоби, степени свободы), алгоритмы (DR-Planner, триангуляция Делоне) и паттерны программирования (C++, умные указатели).
    
- **02 Источники**: Конспекты и выжимки из внешней литературы. Включает разборы фундаментальных книг (например, А.В. Столяров), научных статей по CAD/CFD и документации (NRX API).
    
- **03 Проекты**: Верхнеуровневые заметки по текущим задачам. Содержат архитектурные решения (ADR) и статус по интеграции решателя в плагин SolidFoamNC и разработке UI/UX.
    
- **04 Ежедневник**: Дейли-заметки. Используются для фиксации мыслей, прогресса по коду, инсайтов с пар по высшей математике и отслеживания спортивной рутины.
    
- **05 Шаблоны**: Маркдаун-шаблоны для быстрого создания типизированных заметок (например, шаблон алгоритма или архитектурного решения).
    
- **06 Вложения**: Директория для хранения медиафайлов (изображения, PDF, схемы архитектуры). Скрыта из основного графа.
    
- **99 Метаданные**: Служебная папка. Содержит узловые заметки (MOC — Map of Content) для навигации по темам и агрегирующие скрипты (Dataview).
    

## Ключевые предметные области (Теги)

База знаний охватывает следующий стек технологий и дисциплин:

- **C++ / Architecture**: Управление памятью, умные указатели, интеграция нативного кода с .NET (C++/CLI), оптимизация кэша.
    
- **Qt6 / UI**: Графический фреймворк Graphics View, система сигналов и слотов (Observer), проектирование интерфейсов.
    
- **Math / Algorithms**: Теория графов (условие Ламана, двудольные графы), численные методы (Ньютон-Рафсон, сопряженные градиенты), NURBS.
    
- **САПР / OpenFOAM**: Топология B-Rep, генерация полиэдральных сеток, работа с API геометрических ядер.
    

## Правила ведения базы

- **YAML Frontmatter**: Каждая заметка должна начинаться с метаданных (теги, статус, автор). Это необходимо для работы автоматических выборок.
    
- **Атомарность**: Одна заметка — одна концепция. Если заметка становится слишком большой (например, описание B-Rep), её следует разбить на подтемы и связать ссылками `[[ ]]`.
    
- **Связи**: При упоминании терминов (например, DOF или Граф ограничений) всегда используйте перекрестные ссылки, чтобы локальный граф (Local Graph) корректно отображал зависимости математики от кода.
