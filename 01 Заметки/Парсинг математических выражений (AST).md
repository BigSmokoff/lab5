# Парсинг математических выражений (AST)

Параметрический эскиз требует, чтобы размеры могли задаваться не только числами (например, `15.5`), но и формулами (`(A + B) * sin(C)`). Для этого в решатель необходимо встроить парсер выражений.

**Архитектура решения:**
1. **Лексер (Токенизатор)**: разбивает строку на токены (числа, переменные, операторы, скобки).
2. **Синтаксический анализатор (Парсер)**: использует алгоритм сортировочной станции (Shunting Yard algorithm) Дейкстры или рекурсивный спуск для построения **Абстрактного Синтаксического Дерева (AST)**.
3. **Вычислитель (Evaluator)**: обходит AST (post-order traversal) и вычисляет итоговое значение, подставляя текущие значения переменных из таблицы символов.

Дерево AST позволяет не только быстро пересчитывать значения при изменении переменных, но и аналитически брать производные (Automatic Differentiation), что нужно для точного построения [[Матрица Якоби для системы ограничений]].
