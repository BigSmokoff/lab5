# Метод сопряженных градиентов (Conjugate Gradient)

Продвинутый итерационный метод для решения больших систем линейных алгебраических уравнений (СЛАУ) вида $Ax = b$, где матрица $A$ симметрична и положительно определена.

В 2D САПР матрица Якоби ([[Матрица Якоби для системы ограничений]]) редко бывает симметричной, поэтому чаще используют биконъюгатные градиенты (BiCGSTAB) или GMRES. Однако, изучение классического метода сопряженных градиентов необходимо для понимания того, как работают современные математические пакеты (например, Eigen в C++).

Также этот метод повсеместно применяется в CFD решателях, таких как OpenFOAM, для решения уравнений давления (Pressure Poisson Equation), так как матрица коэффициентов для сетки получается огромной, но сильно разреженной ([[Разреженные матрицы (Sparse Matrices)]]). Изучение дифференциальных уравнений дает мне базу для понимания физики этого процесса.
