# Алгоритм DR-Planner

**Dense Subgraph Reduction Planner (DR-Planner)** — это алгоритм декомпозиции для решения больших систем геометрических ограничений.

Вместо того чтобы решать огромную нелинейную систему (через [[Метод Ньютона-Рафсона в решателе]]) целиком, DR-Planner анализирует [[Граф геометрических ограничений]] и ищет жесткие подграфы (rigid clusters). 

**Шаги:**
1. Поиск минимально плотных подграфов на основе обобщенного [[Условие жесткости Ламана (Laman rigidity)]].
2. Решение подсистемы ограничений для найденного кластера.
3. Редукция: кластер сворачивается в одно абсолютно твердое тело.
4. Повторение до тех пор, пока весь эскиз не свернется в один узел.
