# Параметризация эскиза

Параметризация — это пользовательский уровень работы с [[Геометрический решатель (2D Solver)]]. 
Вместо жестко заданных координат, пользователь оперирует абстракциями: переменными и формулами.

- **Управляющие размеры**: параметры, которые диктуют геометрию.
- **Информационные (справочные) размеры**: просто отображают текущее значение и не участвуют в уравнениях решателя.

В рамках разработки [[Интеграция 2D решателя в препроцессор]] на Qt, параметризация требует создания надежного UI дерева параметров и парсера математических выражений.
